# AbsoluteYoutube
<p align="center">Puissant téléchargeur YouTube pour les utilisateurs de NVDA</p>

**Auteur:** chai chaimee  
**URL:** [https://github.com/chaichaimee/AbsoluteYoutube](https://github.com/chaichaimee/AbsoluteYoutube)

---

## Nouveautés
> ### 🚀 Boostez votre productivité : Téléchargements directs !
> Pourquoi perdre du temps à ouvrir la page vidéo ? Notre fonction **"Focus & Fetch"** vous permet de lancer le téléchargement dès que vous êtes sur un lien vidéo.
>
> * **Vitesse extrême:** Téléchargez en MP3, MP4 ou WAV sans attendre.
> * **Fluidité totale:** Plus besoin de charger la page URL.
> * **Gain de temps:** Le chemin le plus court vers votre contenu.

## Description
AbsoluteYoutube est une extension NVDA avancée pour télécharger des vidéos YouTube directement depuis votre navigateur avec gestion intelligente.
