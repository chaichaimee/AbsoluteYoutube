# AbsoluteYoutube
<p align="center">Мощный загрузчик YouTube для пользователей NVDA</p>

**Автор:** chai chaimee  
**URL:** [https://github.com/chaichaimee/AbsoluteYoutube](https://github.com/chaichaimee/AbsoluteYoutube)

---

## Что нового
> ### 🚀 Ускорьте свою работу: загрузка прямо по ссылке!
> Зачем открывать страницу видео? Функция **"Focus & Fetch"** позволяет начать загрузку сразу, как только вы сфокусировались на ссылке!
>
> * **Мгновенно:** MP3, MP4 или WAV прямо из результатов поиска.
> * **Без пауз:** Не ждите загрузки страницы.
> * **Эффективно:** Получайте контент в рекордные сроки.

## Описание
AbsoluteYoutube — это продвинутое дополнение для NVDA, позволяющее скачивать медиа с YouTube в форматах MP3, MP4 или WAV прямо из браузера.
