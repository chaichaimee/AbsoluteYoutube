## Description
AbsoluteYoutube is an advanced NVDA add-on that lets you download YouTube videos and media in MP3, MP4, or WAV formats directly from your browser. It includes smart background systems for efficient, resumable downloads, video trimming, snapshots, short URL copying, and a full failed download manager.

## Hot Keys
| Gesture | Action |
| :--- | :--- |
| **NVDA+Y** | Download (1 tap: MP3, 2 taps: MP4, 3 taps: WAV) |
| **CTRL+Shift+Y** | Menu (1 tap: Context Menu, 2 taps: Open Folder) |
| **NVDA+Shift+Y** | Toggle playlist mode on/off |
| **ALT+Windows+Y** | Cycle MP3 quality (128 → 320 kbps) |

---
**Note:** All features are highly configurable in NVDA Settings → Absolute YouTube.
