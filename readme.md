## Description
AbsoluteYoutube is an advanced NVDA add-on that lets you download YouTube videos and media in MP3, MP4, or WAV formats directly from your browser. It includes smart background systems for efficient, resumable downloads, video trimming, snapshots, short URL copying, and a full failed download manager – all accessible with simple gestures and menus.

<br>

## Hot Keys
**NVDA+Y** – Download Command (Multi-tap Detection)  
• Single Tap: Download as MP3 (High quality)  
• Double Tap: Download as MP4 (Video)  
• Triple Tap: Download as WAV (Uncompressed audio)

**CTRL+Shift+Y** – Options & Tools  
• Single Tap: Open context menu (Access all tools)  
• Double Tap: Open download destination folder  
• **Triple Tap: Open the New Search Dialog** (Access Unbound Search results)

**NVDA+Ctrl+Y** – Auto-Download Toggle  
• Switch between instant download and **Queue Mode**. When disabled, links are sent to the Download List Manager for later action.

**NVDA+Shift+Y** : Toggle playlist mode on/off

**ALT+Windows+Y** : Cycle MP3 quality (128 → 192 → 256 → 320 kbps)

> All shortcuts use tap detection (time window ~0.4 seconds). You can remap them in NVDA → Input Gestures.

## Key Features Explained
* **1. Unbound Search Dialog (Triple Tap Shift+Ctrl+Y)**  
  This is not your standard search. By triggering the Triple Tap, you enter a specialized search interface. Unlike the YouTube website which limits results based on your history, this tool fetches raw data, giving you access to a wider variety of videos and information that otherwise wouldn't appear.

<br>

* **2. Favorite Channel Collection (Step-by-Step Guide)**  
  Never lose track of your favorite creators. Here is how to build your collection:  
  * **Step 1:** Go to YouTube and copy the URL of the channel you want to follow (e.g., youtube.com/@ChannelName).
  * **Step 2:** Open the AbsoluteYoutube Context Menu (Single Tap Ctrl+Shift+Y) and select "Favorite Channels".
  * **Step 3:** Select the option to add a new channel and paste your copied URL.
  * **The Benefit:** Once added, every time you open this channel through the dialog, the system automatically checks for new video uploads and presents them in a list for you instantly.

<br>

* **3. Download List Manager & Smart Queue (NVDA+Ctrl+Y)**  
  If you are busy and don't want to download immediately, press **NVDA+Ctrl+Y** to turn off Auto-Download. All your requested files will be sent to a "Queue".  
  • To process them, open the **Download List Manager** from the Context Menu.  
  • Right-click any item to start the download, delete it, or retry, giving you the same control as the Download Fail Manager.

<br>

* **4. Smart Background Download System**  
  • Queue Manager: Downloads run one-by-one to save CPU/RAM.  
  • Resume on Restart: Interrupted downloads are saved and resume automatically when NVDA restarts.  
  • Auto File Repair: Cleans up corrupted temp files before starting.  
  • Skip Existing: Prevents downloading the same file twice.

<br>

* **5. Trim Video Clips (uTubeTrim)**  
  Open context menu → Trim setting. Set start/end time and choose your format. Perfect for grabbing specific segments without downloading the whole video.

<br>

* **6. Download Fail Manager**  
  Persistent list of failed items. Right-click any item to retry, clear, or download all remaining tasks.

<br>

> **Note:** All features are highly configurable in NVDA Settings → Absolute YouTube. Shortcuts can be changed in Input Gestures.
